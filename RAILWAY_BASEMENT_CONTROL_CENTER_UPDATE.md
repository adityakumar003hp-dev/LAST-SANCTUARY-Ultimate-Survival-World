# Railway basement control centre update

- Relocated the sanctuary railway dispatch console out of the upper command/utility floor and into a dedicated basement room below the apartment.
- Added one panoramic train information screen, two auxiliary monitors on each side, a dispatch desk, keyboard and status lamps.
- Added the basement interaction prompt and a six-service dispatch interface with route map, arrival/departure board, condition, speed, distance travelled/remaining, next station and stopping station.
- Keyboard shortcuts: `1`–`6` select a service, Left/Right cycle services, `Space` toggles dispatch hold/resume, `H` sends a hold order, `R` reviews the selected route, `Esc` closes the console.
- The old upper-floor command desk and its collision prop were removed. Other apartment floors and utilities remain intact.

The dashboard currently uses authored in-game timetable/demo values for the six services; it is a dispatch UI prototype and is not yet wired to live train telemetry or physical train control.
